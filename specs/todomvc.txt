Crie uma aplicação web de lista de tarefas no estilo do TodoMVC, usando só HTML, CSS e JavaScript puro, que funcione abrindo o index.html direto no navegador, sem servidor. Os textos da tela podem ficar em inglês, como no TodoMVC.

No topo, coloque um campo para digitar uma nova tarefa; ao apertar Enter, ela entra na lista. Cada tarefa precisa ter uma caixinha para marcar como concluída (e desmarcar), um jeito de editar o texto com duplo clique e um botão para excluir que aparece quando passo o mouse. Também quero uma opção para marcar todas as tarefas como concluídas de uma vez.

Embaixo da lista, mostre quantas tarefas ainda faltam, filtros para ver todas, só as ativas ou só as concluídas, e um botão para limpar as concluídas.

As tarefas precisam continuar salvas quando eu recarregar a página. Deixe o visual limpo e centralizado, parecido com o TodoMVC, e que funcione bem no celular.
